# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.0   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an e-mail to security@thenovanodes.com or report it directly via GitHub Security Advisories. We will respond as soon as possible and take all reports seriously. Please do not report security vulnerabilities through public GitHub issues.
