# Contributing to TheNovaNodes Portal

We welcome contributions to TheNovaNodes Portal! By contributing, you help improve the official showcase for our AI Agent Infrastructure.

## Tech Stack
This project uses:
- **Next.js 16 (App Router)**
- **React 19**
- **TypeScript**
- **Tailwind CSS v4**

## Development Workflow

1. Fork the repository and clone your fork.
2. Ensure you have Node.js >= 20 installed.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Before committing, ensure the build succeeds and linting passes:
   ```bash
   npm run build
   npm run lint
   npm run test
   ```

## Pull Request Process

1. Create a descriptive feature branch (`feature/your-feature-name`).
2. Adhere to our [DESIGN.md](./DESIGN.md) for brand identity and UI/UX consistency.
3. Open a Pull Request against the `main` branch.
4. Ensure all CI checks pass.
5. All PRs require review and approval from ZaVLab before merging.

Thank you for contributing!
